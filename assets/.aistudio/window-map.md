# Window map — night city pomodoro background

Source image: `cityscape_windows_transparent.png` — **688 × 1536 px**, aspect ratio **688/1536 ≈ 0.4479**.

Every window in the PNG is a fully transparent hole (alpha = 0). To make a window "light up",
put a coloured/glowing element **behind** the image at the coordinates below.

All coordinates are **percentages of the image box**, so they stay correct at any screen size.

The rectangles are already inset by 1 px on each side, so a glow never bleeds over the window
frame — render the overlay elements with `border: none`.

## How to place them

The image must sit in a box with the **same aspect ratio** as the source, otherwise percentages
drift. Easiest way:

```html
![](cityscape_windows_transparent.png)
```

```css
.city {
  position: relative;
  aspect-ratio: 688 / 1536; /* keeps the % coordinates valid on every screen */
  width: 100%;
  max-height: 100vh;
  margin-inline: auto;
  background: #0b0714; /* shows through unlit windows */
  overflow: hidden;
}

.city-img {
  position: absolute; inset: 0;
  width: 100%; height: 100%;
  display: block;
  object-fit: fill; /* fill, not cover — the box already has the right ratio */
  pointer-events: none;
  z-index: 2;
}

.glow-layer { position: absolute; inset: 0; z-index: 1; }

.window {
  position: absolute;
  border: none; /* no borders — the PNG provides the frames */
  border-radius: 6%;
  background: #0b0714; /* dark = window is off */
  transition: background .6s ease, box-shadow .6s ease;
}

.window.lit {
  background: #fff3c4;
  box-shadow: 0 0 14px 4px rgba(255, 228, 140, .55);
}
```

```jsx
// windows come from window-map.json
{windows.map(w => (
  key={w.id}
  className={`window ${lit.has(w.id) ? 'lit' : ''}`}
  style={{ left: `${w.left}%`, top: `${w.top}%`, width: `${w.width}%`, height: `${w.height}%` }}
  />
))}
```

If the device screen is a different shape and you want the art to bleed edge-to-edge, use
`object-fit: cover` on **both** the image and the `.glow-layer` — wrap the layer in the same
sized/positioned box as the image rather than in the viewport, so the two are cropped identically.

## Suggested pomodoro behaviour

The `tower` group is the natural progress bar: 70 windows = 14 floors × 5 windows.

`lightOrder` in the JSON runs **bottom-left → top-right**, so lighting window `n` after the n-th
completed session makes the building fill up from the ground.

- session finished → add `.lit` to the next id in `lightOrder`
- long break → light a whole floor at once
- day reset → remove `.lit` from everything
- `skyline` windows work well as slow random ambient flicker, independent of the timer
